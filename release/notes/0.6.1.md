# Space Sniffer v0.6.1

Downloads now state both their operating system and architecture. The shared updater v0.4.1 recognizes the new names and falls back to simpler historical names.

## Improved

- Windows: `SpaceSniffer-v0.6.1-windows-amd64.exe`.
- Ubuntu: `SpaceSniffer-v0.6.1-ubuntu-amd64.deb`.
- Update discovery prefers an exact platform-and-architecture filename, then matching architecture-qualified names with or without version/platform, followed by platform-only and historical names. `SpaceSniffer-x64.exe`, `SpaceSniffer-x86.exe`, and `SpaceSniffer-windows.exe` are supported for the appropriate build. amd64/x64/x86_64, i386/x86/i686, and arm64/aarch64 are separate architecture groups; downloaded package/PE metadata must still match. GitHub asset ordering does not affect selection.
- An invalid checksum, unexpected URL or duplicate preferred filename stops the update instead of silently selecting another file.

## Download and upgrade

Choose the `windows-amd64.exe` or `ubuntu-amd64.deb` file for manual installation. Ubuntu installs with `sudo apt install ./SpaceSniffer-v0.6.1-ubuntu-amd64.deb`.

Use the existing in-app updater to upgrade from earlier versions. This release retains byte-identical files named `SpaceSniffer-v0.6.1.exe` and `space-sniffer_0.6.1_amd64.deb` for those older clients. They are compatibility copies, not different builds. All four filenames are covered by SHA256SUMS.txt. Existing published releases remain unchanged.
