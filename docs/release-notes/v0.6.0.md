# Space Sniffer v0.6.0

This release brings Ubuntu desktop support to the same Rust application used on Windows, adds optional volume colors, and fixes Linux root scans and live-update responsiveness.

## Added

- Ubuntu x86-64 `.deb` with an application-menu launcher, icon and runtime dependencies. The published package is built on Ubuntu 22.04.
- Mounted filesystem shortcuts and optional **Color by volume**, including a legend and volume labels in file details. The setting persists between launches. Volume identity represents a filesystem, including partitions, network shares and encrypted devices; it does not resolve the individual disks behind RAID or LVM.
- Verified Ubuntu in-app updates through the shared rust-auto-updator v0.3.1 core. Downloads are checked against SHA-256 and package identity; apt installs through the standard administrator authorization dialog. Cancellation keeps the app open, and successful installation restarts it as the normal user with the previous scan root.

## Improved

- The scanner, model, live updates, filters, navigation and treemap remain one shared project across platforms.
- Large root replacements prepare their model and filter on a worker while retaining the previous map. Package installation also runs off the UI thread.
- Linux native watching continues around unreadable directories instead of switching the entire root to frequent polling.
- Release checks now build and test both Windows and Ubuntu before publishing their assets and combined checksums.

## Fixed

- Scanning `/` no longer counts `/proc/kcore` as approximately 128 TiB of disk files. Scan previews, full scans and live watching share exclusions for kernel interfaces, nested RAM filesystems, Snap images, container overlays and recursive bind mounts. Other data disks remain included; ordinary sparse files retain their logical lengths.
- Mount paths with escaped characters or non-UTF-8 bytes preserve their identity, and bind aliases use the same volume color.

## Download and upgrade

**Windows x86-64:** download `SpaceSniffer-v0.6.0.exe`, or use the existing in-app updater. It remains a portable executable.

**Ubuntu x86-64:** download `space-sniffer_0.6.0_amd64.deb` and run `sudo apt install ./space-sniffer_0.6.0_amd64.deb`. Launch Space Sniffer from the application menu. After this initial package installation, future versions can be installed from **Updates**. Earlier experimental Ubuntu builds without the Debian updater require this initial manual installation. An administrator password is required to change the system package; the app itself runs as your normal user.

File totals represent accessible logical file sizes rather than allocated blocks or free disk capacity. Use **F5** after changing mounts. macOS remains experimental and is not distributed as a signed application in this release.
