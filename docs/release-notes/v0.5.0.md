# Space Sniffer v0.5.0

Space Sniffer now supports six interface languages and a light theme, with language and appearance controls available directly in the sidebar.

## Added

- Choose English, Russian, French, German, Spanish, or Italian without restarting. The selection is saved between launches.
- Switch between Light and Dark directly in the sidebar. The choice applies to the main interface, controls, popups, help and update settings, and is saved with the existing settings.
- Localized scan and watcher status, filter validation, export and file-picker titles, selection actions, help, and update controls.

## Improved

- English remains the complete default and fallback. Filenames, paths, filter expressions, technical OS details, and upstream release notes retain their original content.
- Existing installations retain their update-check preference, window settings, and dark appearance. The new preferences are added without replacing existing settings.
- Developer capture mode supports a selected language and theme, requires isolated settings, validates the requested view, and exits after saving real CPU-rendered frames without writing settings.

## Fixed

- A Windows shutdown requested during frame processing now completes without waiting for unrelated system input. Normal idle windows continue to sleep until useful work arrives.

## Download and upgrade

Download `SpaceSniffer-v0.5.0.exe` for Windows x86-64. This is one portable executable with no separate updater installation. Space Sniffer 0.4.2 can discover and install the update from its Updates window; settings and scanned files are preserved. Linux and macOS remain source builds, with macOS experimental.

The Windows source and local checks cover catalog completeness and matching format fields, preference migration and persistence, UI repaint settling for all six languages in both themes, scanner/model workflows, and retained CPU/GDI scheduling. Real captures and bounded native-window render measurements are recorded in the version's validation notes. Physical keyboard/tray interactions, platform-native file dialog language, and Linux/macOS runtime behavior were not verified in this update.
