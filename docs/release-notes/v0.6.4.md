# Space Sniffer v0.6.4

The Linux treemap highlights application packages and portable apps in its three-color palette.

## Fixed

- On Ubuntu and other Linux systems, the purple category covers `.deb`, `.AppImage`, `.snap`, and `.flatpak` files. The key shows those extensions. On Windows, the same category covers `.exe` files.

## Download and upgrade

Use `SpaceSniffer-v0.6.4-ubuntu-amd64.deb` on Ubuntu x86-64 or `SpaceSniffer-v0.6.4-windows-amd64.exe` on Windows x86-64.
