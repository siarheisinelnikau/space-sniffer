# Space Sniffer v0.4.2

This release changes Windows rendering to reduce graphics-related interference during large scans and adds in-app GitHub updates.

## Added

- Check the latest stable GitHub release at startup or manually from Updates. The startup-check preference is enabled by default and can be disabled persistently.
- Download updates in the application with progress, cancellation, size and SHA-256 verification, then install and restart with the current root.
- Read release notes in Updates, with clear network and rate-limit errors and manual release links for unsupported platforms.

## Improved

- Windows renders egui on the CPU and presents a GDI bitmap, without creating an application OpenGL or DirectX context. The interface and treemap controls remain shared with other platforms.
- Idle windows wait for events, repeated repaint requests are coalesced, and minimized scans process results without painting the interface.
- Windows filesystem workers use background CPU, disk, and memory scheduling to give foreground applications priority.
- Standalone Windows downloads use `SpaceSniffer-v0.4.2.exe`. The updater also recognizes executable names used by earlier releases.

## Fixed

- Scanning and update-check spinners no longer continuously repaint the entire map while waiting for results.
- Background result delivery avoids egui's redundant settling frame, and processing a scan chunk requests another application frame only when queued work remains.
- Existing Windows eframe settings, window geometry, and the update-check preference are retained by the new native host.

## Download and upgrade

Download `SpaceSniffer-v0.4.2.exe` for Windows x86-64 and run it from a writable folder. The download remains one portable executable. Version 0.4.1 predates the in-app updater, so upgrade from that release manually once. Linux and macOS remain available from source and retain their existing graphics backend; macOS is experimental.

Local Windows checks include scan/model tests, idle and minimized repaint counters, CPU rendering benchmarks, and a bounded C: scan with automatic close. A bounded scan is not a completed whole-drive scan or a guarantee of frame latency on every computer; see [performance notes](https://github.com/siarheisinelnikau/space-sniffer/blob/main/docs/performance.md).
