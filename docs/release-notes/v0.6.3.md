# Space Sniffer v0.6.3

The treemap uses three colors to distinguish folders, `.exe` files, and other files.

## Improved

- Folder color stays consistent at every nesting level. The default palette uses dark blue for folders, purple for `.exe` files, and gray-blue for all other files.
- A key above the map shows the three colors in the default and Classic palettes.

## Download and upgrade

Use `SpaceSniffer-v0.6.3-windows-amd64.exe` on Windows x86-64 or `SpaceSniffer-v0.6.3-ubuntu-amd64.deb` on Ubuntu x86-64.
